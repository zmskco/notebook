# 笔记本（notebook）

笔记本，所见即所得，界面能看到的功能就是有，看不到的就是没有。

一个类似 VS Code 的本地 Markdown 笔记本，使用 Rust + GPUI 编写。所有笔记都是普通的 `.md` 文件，保存在工作区目录里，不联网、不上传。

## 功能

### 工作区与资源管理器

- 启动时以运行目录下的 `notes/` 作为工作区（不存在会自动创建）
- 会记住上次的工作区与打开的标签，下次启动自动恢复（已删除的文件会被跳过）
- 侧栏右上角可**切换工作区**，或在资源管理器中打开当前工作区
- 目录树按「文件夹在前、文件在后」排序，展开状态会保留到本次运行结束
- 右键菜单：新建笔记、新建文件夹、重命名、删除、在资源管理器中显示
- 选中文件后可用 `F2` 重命名、`Delete` 删除；有未保存改动的文件会在树上显示标记

### 全局搜索

侧栏的搜索图标（或 `Ctrl+Shift+F`）打开搜索面板：

- 边输入边在当前工作区里查找，结果显示文件、行号与该行内容，命中部分会高亮
- 可切换是否区分大小写
- 点击结果打开对应文件并定位到那一行
- 在「替换为」里填写内容后可全部替换，替换前会提示会改动多少个文件的多少处；已打开的文件直接改在编辑器里并保存
- 自动跳过隐藏目录与大文件

### 多标签编辑

- 点击文件打开新标签，重复点击会切换到已打开的标签
- 标签上的圆点表示有未保存修改，关闭时会询问是否保存
- 四种视图，可用 `Ctrl+Shift+V` 轮换：
  - **所见即所得**：直接排版，边写边看效果
  - **源码**：只显示 Markdown 原文
  - **演示**：只显示渲染后的 Markdown
  - **对照**：左侧源码、右侧演示，中间分隔线可拖动调整比例
- 状态栏显示操作提示与当前文档的字数、行数、保存状态

### 文档内查找替换

`Ctrl+F` 在当前文档里查找，`Ctrl+H` 同时打开「替换为」，再按一次同样的快捷键收起。四种视图都能用（源码视图里库自带的查找栏已关闭，统一用这一个）：

- 输入即高亮，`Enter` / `Shift+Enter` 或上下箭头在命中之间跳转，显示 `当前/总数`
- 可切换是否区分大小写
- 「替换」只改当前一处，「全部替换」改完整个文档；改动会同步到所有视图
- 源码与对照视图里，当前命中会被选中；演示视图（含对照右侧）里所有命中带底色，并自动滚到当前一处

### 排版

顶部工具栏可随时调整，互不影响内容：

| 项目 | 可选值 |
| --- | --- |
| 字体 | 黑体 / 宋体 / 霞鹜文楷 / 阿里巴巴普惠体 |
| 字号 | 10 / 12 / 14 / 16 / 18 / 20 / 22 / 24 / 28 / 32 / 36 |
| 背景 | 简白 / 雅致 / 黑夜 / 绿茵 |
| 正文宽度 | 宽 / 标准 / 窄 |

霞鹜文楷与阿里巴巴普惠体在编译期通过 `include_bytes!` 直接嵌入可执行文件，无需安装字体，也不会因为系统缺字体而回退。

### 源代码管理

侧栏的 Git 视图可以：

- 查看当前分支、切换分支、拉取、推送
- 查看改动列表，单独暂存 / 取消暂存 / 全部暂存 / 丢弃改动
- 填写提交说明并提交
- 点击改动查看差异，点击历史提交查看该次提交的内容
- 历史提交面板可上下拖动分隔条调整高度，提交多时可滚动查看
- 工作区不是仓库时可一键初始化

Git 操作通过本机 `git` 命令执行，子进程使用 `CREATE_NO_WINDOW`，不会闪出黑框。

### 欢迎文档

首次启动（工作区为空）或切换到空目录时，程序会自动创建并打开 `欢迎.md`。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+S` | 保存当前文件 |
| `Ctrl+W` | 关闭当前标签 |
| `Ctrl+Tab` | 切换到下一个标签 |
| `Ctrl+Shift+Tab` | 切换到上一个标签 |
| `Ctrl+Shift+V` | 在所见即所得 / 源码 / 演示 / 对照之间切换 |
| `Ctrl+F` | 在当前文档里查找 |
| `Ctrl+H` | 在当前文档里替换 |
| `Ctrl+Shift+F` | 打开全局搜索 |
| `F2` | 重命名目录树中选中的文件（焦点在目录树时） |
| `Delete` | 删除目录树中选中的文件（焦点在目录树时） |
| `F5` | 刷新目录树与 Git 状态 |

## 构建与运行

需要 Rust 1.85+（edition 2024）与系统 `git`。

```bash
cargo run              # 调试运行
cargo build --release  # 发布构建
```

工作区默认是运行目录下的 `notes/`，所以请在项目根目录运行，或把可执行文件放到希望作为上级目录的位置。

## 目录结构

```
notebook/
├─ src/
│  ├─ main.rs       入口：窗口、快捷键、工作区根目录
│  ├─ app.rs        主界面：侧栏、标签、编辑器、对话框、状态栏
│  ├─ fs_ops.rs     文件/目录操作、欢迎文档模板
│  ├─ git.rs        git 命令封装（状态、差异、提交、分支）
│  ├─ search.rs     全局搜索与批量替换
│  └─ file_icons.rs 彩色文件图标（栅格化并缓存）
├─ assets/
│  ├─ fonts/       内嵌字体（霞鹜文楷、阿里巴巴普惠体）
│  ├─ file-icons/  文件图标用的 Material SVG
│  ├─ icon.ico     应用图标（16–256 多尺寸）
│  └─ app.rc       Windows 图标资源脚本
├─ build.rs        把 icon.ico 编进可执行文件
├─ notes/          默认笔记目录
└─ Cargo.toml
```

## 技术栈

- [gpui-kit](https://crates.io/crates/gpui-kit) 0.8.1 + gpui-pre —— 界面与组件
- gpui-kit-markdown-editor 0.1.2 —— 所见即所得编辑器与 Markdown 渲染
- embed-resource 3.0.12（构建依赖）—— 把图标写入 exe 资源

## 说明

- 内嵌字体使可执行文件约 68 MB，换来完全离线、免安装字体
- 任务栏与 Alt+Tab 的图标来自 exe 资源；如果桌面快捷方式指向旧的可执行文件，需要改指向新的 `notebook.exe`
- 笔记是普通 Markdown 文件，可以直接用其他编辑器打开，也可以用 Git 管理
