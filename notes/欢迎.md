# 欢迎使用笔记本

所见即所得的 Markdown 笔记本，有的功能都在界面上。

## 界面

- **左侧侧栏**：顶部三个图标切换资源管理器 / 搜索 / 源代码管理
- **资源管理器**：目录树展示工作区内的文件夹与 Markdown 文件
- **源代码管理**：查看 Git 分支、改动与历史提交，暂存、提交、拉取、推送
- **中间编辑区**：多标签，标签上的圆点表示有未保存的修改
- **底部状态栏**：操作提示、保存状态、字数与行数

## 资源管理器

- 点击文件即可打开；点击文件夹展开或收起
- 右键文件或文件夹可新建笔记、新建文件夹、重命名、删除、在资源管理器中显示；在目录树空白处右键只在根目录新建
- 新建和重命名都是**就地输入名字**，不弹窗：选中文件夹就在它里面新建，选中文件就在同级新建，没有选中就在根目录。回车确认、`Esc` 取消，点别处自动放弃
- 名字重复、为空或含 `\ / : * ? " < > |` 时，会在状态栏就地提示并保留输入框，不会弹窗；只有删除才会弹确认框
- 侧栏工具栏的新建图标与右键菜单行为完全一致
- 选中文件后按 `F2` 重命名、`Delete` 删除、`F5` 刷新
- 侧栏与编辑区之间的分隔条可以左右拖拽，调整侧栏宽度
- 侧栏右上角两个图标：切换工作区 / 在资源管理器中打开当前工作区

## 全局搜索

侧栏的搜索图标，或按 `Ctrl+Shift+F`：

- 边输入边在当前工作区里查找，结果显示文件、行号与该行内容，命中部分会高亮
- 可切换是否区分大小写，点击结果直接打开并定位到那一行
- 填写「替换为」后可全部替换，替换前会提示会改动多少个文件的多少处
- 自动跳过隐藏目录与大文件

## 四种视图

编辑区右上角四个按钮，或按 `Ctrl+Shift+V` 轮换：

1. **所见即所得**：直接排版，点哪里就在哪里编辑
2. **源码**：只看 Markdown 原文
3. **演示**：只看渲染后的 Markdown
4. **对照**：左侧源码、右侧演示，中间分隔线可拖动

## 查找替换

- `Ctrl+F` 在当前文档里查找，`Ctrl+H` 同时打开「替换为」，工具栏上的「查找」「替换」按钮效果相同
- 输入即高亮，`Enter` / `Shift+Enter` 或上下箭头在命中之间跳转，显示「当前/总数」
- 「替换」只改当前一处，「全部替换」改完整个文档，四种视图都会同步
- 再按一次同样的快捷键收起；只点「查找」时会把替换栏收掉、保留查找栏

## 排版

顶部工具栏可以随时调整，内容不会丢：

- 字体：黑体 / 宋体 / 霞鹜文楷 / 阿里巴巴普惠体（后两者内置于程序）
- 字号：10 – 36
- 背景：简白 / 雅致 / 黑夜 / 绿茵
- 宽度：宽 / 标准 / 窄

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+S` | 保存当前文件 |
| `Ctrl+W` | 关闭当前标签 |
| `Ctrl+Tab` | 切换到下一个标签 |
| `Ctrl+Shift+Tab` | 切换到上一个标签 |
| `Ctrl+Shift+V` | 在所见即所得 / 源码 / 演示 / 对照之间切换 |
| `Ctrl+F` | 在当前文档里查找 |
| `Ctrl+H` | 在当前文档里替换 |
| `Ctrl+Shift+F` | 打开全局搜索 |
| `F2` | 重命名选中的文件或文件夹（就地输入） |
| `Delete` | 删除选中的文件或文件夹（弹确认框） |
| `F5` | 刷新目录树与 Git 状态 |

> 笔记就是普通的 .md 文件，可以直接用其他编辑器打开，也可以用 Git 管理。
